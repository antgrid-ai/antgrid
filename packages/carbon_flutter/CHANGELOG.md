# Changelog

## 0.1.0 (unreleased)

Initial release.

- Foundations: Carbon v11 semantic color roles with the White, Gray 10,
  Gray 90 and Gray 100 themes, explicit compact and touch density, density-
  resolved typography (IBM Plex Sans and Mono bundled), spacing, size, border
  and motion tokens, layer helpers, bundled Carbon icons as path data, and
  overridable localizations.
- `CarbonTheme`, `CarbonLayer`, `CarbonLayerSurface` and `CarbonScopeRelay`
  for scoping theme, density and layer context, including into Navigator
  routes.
- `CarbonContrast` for WCAG contrast checks of built-in and custom palettes.
- `CarbonLicenses.register()` for the bundled font and icon notices.
