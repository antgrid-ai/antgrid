# Source code for Antgrid distributions

Every official build records its full Git commit in the `SOURCE_COMMIT` build
define. The Help/About screen links to that exact revision. Tagged releases
also publish `antgrid-<tag>-source.tar.gz`, `antgrid-<tag>.spdx.json`, and
`SHA256SUMS` beside the executables at:

https://github.com/antgrid-ai/antgrid/releases

The tag-specific source archive is the corresponding Source Code Form for the
MPL-covered files in that build and is retained for as long as the executable
is distributed. Unchanged builds may be mirrored without a separate agreement:
this embedded notice and the recorded commit identify the exact corresponding
source.

`LICENSING.md` maps every path in the repository and states what MPL-2.0 does
and does not reach. Third-party and brand materials remain under the terms
listed in `THIRD-PARTY.md` and `BRAND-ASSETS-LICENSE.md`.
